# Employee Management System (C++)

## 📌 About the Project
This project is a **console-based Employee Management System** developed in **C++**.  
It includes a **login/signup system** and allows users to manage employee records using a **menu-driven interface**.

The system supports full **CRUD operations** (Create, Read, Update, Delete) and is designed to practice **structures, arrays, functions, and program flow control**.

---

## 🛠️ Technologies Used
- C++
- Structures (`struct`)
- Arrays
- Functions
- Conditional Statements
- Loops
- Console Input/Output
- Windows-specific functions (`Sleep`, `system("CLS")`)

---

## ✨ Features
- User **Signup & Login** system  
- Add employee records  
- Display all employee records  
- Search employee by ID  
- Update employee information  
- Delete specific employee or all records  
- Menu-driven interface  
- Input validation and feedback messages  

---

## ⚙️ How It Works
1. User creates an account (signup).  
2. User logs in using username and password.  
3. After login, a menu is displayed with multiple options.  
4. User can add, view, search, update, or delete employee records.  
5. Records are stored in an array during program execution.  
6. User can log out or exit the program.
